Smart Investment Calculator

About

Smart Investment Calculator is a Python GUI application that helps users calculate returns on SIP and Lump Sum investments. It provides an easy way to estimate future investment value and displays the results visually using a pie chart.

 Features

* SIP return calculation
* Lump Sum return calculation
* Simple and user-friendly interface
* Input validation
* Pie chart visualization of results

 Technologies Used

* Python
* CustomTkinter
* Matplotlib
* NumPy

 How to Run

1. Install the required libraries:

pip install customtkinter matplotlib numpy


2. Run the program:


python main.py


 Usage

* Enter the investment amount.
* Select the investment tenure.
* Enter the expected rate of return.
* Click **Calculate** to view the results.
* Click **Details** to see the pie chart.

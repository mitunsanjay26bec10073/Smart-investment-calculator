# Smart Investment Calculator

## Problem Statement

Many people want to invest their money but find it difficult to calculate the future value of their investments manually. This project provides a simple way to estimate returns on SIP and Lump Sum investments.

## Scope of the Project

The application allows users to calculate investment returns based on the investment amount, tenure, and expected rate of return. It also provides a graphical representation of the results using a pie chart.

## Target Users

* Students
* Beginner investors
* Individuals interested in financial planning

## High-Level Features

* SIP Calculator
* Lump Sum Calculator
* Investment return visualization using pie charts
* Input validation and error handling
* Simple graphical user interface
